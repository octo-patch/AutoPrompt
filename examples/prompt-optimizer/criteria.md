# Fitness Criteria: Blog Post System Prompt

## Goal
Evolve the best system prompt for generating short, high-quality blog posts from a topic.

## What "better" means (in priority order)
1. **Specificity** — the prompt gives clear, actionable instructions (not vague "be helpful")
2. **Structure** — the prompt defines format, length, tone, and audience
3. **Constraints** — the prompt includes guardrails (what NOT to do) to prevent generic output
4. **Voice** — the prompt establishes a distinct, consistent writing style
5. **Completeness** — covers edge cases (what if the topic is broad? narrow? controversial?)

## Scoring Guide
- 0-2: vague, generic ("be helpful and write well")
- 3-4: has some structure but still too broad
- 5-6: decent instructions with clear format expectations
- 7-8: well-crafted with tone, constraints, and examples
- 9-10: production-quality prompt that consistently produces excellent output
